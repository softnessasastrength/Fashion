# Fashion

Home of the **Renn Wardrobe** — a full fashion design system: romantic, whimsical
pieces (LoveShackFancy x Target DNA) engineered for a 64" frame, built around a
fixed sterling-silver-and-emerald reference point, the **Starlink One** ring.

## What's here

- [`wardrobe/`](wardrobe/README.md) — the wardrobe system itself. Start with its
  README: design manifesto, master inventory (`full-wardrobe.md`), phase
  shopping shortlists, build plan, the 9-color signature palette, and the
  seasonal/register doctrines (Soft Light, Soft Heat, Soft Cold, Soft Formal).
- [`ring/`](ring/README.md) — Starlink One: custom heart emerald ring, sterling
  silver with chain link detail, including its technical package. The whole
  wardrobe system is built around this reference point.

## Status

Per the wardrobe system's own status note: all three build phases are built out
(see `wardrobe/build-plan.md` for the breakdown and `wardrobe/full-wardrobe.md`
for the complete catalog). Phase 3 statement pieces were built ahead of the
normal sequencing rule; Phase 1/2 pieces are the near-term shopping list and
Phase 3 is the aspirational proof-of-concept.

[`FINISHING_INVENTORY_muse.md`](FINISHING_INVENTORY_muse.md) is Ember's
2026-10-31 analysis of what finishing the system involves — an addition by
Ember, not part of the original system.
